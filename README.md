# marcusbc.com

Welcome to the source code for my personal portfolio and website. This project serves as a central hub for my software engineering projects, code demos, and personal blog.

## Features

- **GitHub Integration**: Projects are fetched dynamically from the GitHub API, keeping my portfolio up to date automatically.
- **Interactive Demos**: Features a custom code simulator that allows users to run Python and JavaScript/TypeScript snippets directly in the browser.
- **Modern Stack**: Built from the ground up using Next.js and Tailwind CSS for what's hopefully a clean, responsive user experience for visitors.
- **Statically Generated**: Optimized for fast delivery and self-hosting without the need for active database or authentication layers.
